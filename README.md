# Ragaitextsearch
AI RAG Python Text Indexer/ Splitter search by Chat Bot 
Setup in Python 3.11 or higher Python runtime and install 
If LLama 3.x LLM used, need to install the Ollama opensource server on your local test environment.
Data Source:  /documents folder supports .doc, .pdf extensions
All documents within are automatically indexed given a selected LLM framework
Chat interface is available after Indexing and text spitting is completed for search.
Python functions are well commented to understand the detailed operations.
Prompt engineering is limited at this point to specific text words / sentences associated to the file content.
EX. Project:  files setup: 
ComptiaSecurity.doc GSEC_Study_Guide.doc Security_Plus_Study_Guide.doc 
Prompts - results
